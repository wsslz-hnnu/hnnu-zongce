# 湖南师范大学医学部 · 本科生综合测评计算器

一个**纯前端、单文件、零依赖**的综测算分工具。依据《湖南师范大学医学部本科生综合素质测评实施细则》制作，在浏览器本地运行，数据不上传任何服务器。

> ⚠️ 本项目为个人自制的辅助工具，非学校官方系统。最终分数以学部综测小组核定结果为准。

---

## 功能

### 三大模块完整实现

| 模块 | 权重 | 内容 |
|------|------|------|
| **F1 基本素质** | 10% | A1 思想政治、A2 道德品质、A3 学习态度、A4 组织纪律、A5 身心健康 |
| **F2 课程成绩** | 65% | 学分加权平均，支持优/良/中/及格/不及格自动折算 |
| **F3 创新实践** | 25% | B1 职业技能、B2 学科竞赛、B3 科技学术、B4 文艺宣传、B5 社会工作、B6 社会实践、B7 文体竞赛、B8 劳育 |

**总分 = F1 × 10% + F2 × 65% + F3 × 25%**

### 细则规则落地

- 每项封顶 20 分，单项扣分上限 20 分，一票否决 F1 归零
- 「5531」指标自动判定（3 讲座 + 5 志愿 + 5 文体 + 1 成长辅导），达标自动给 B1、B2、B3、B4、B6、B7 各加 5 分
- 团队项目角色折算：第一负责人 100%、第二三负责人 50%、其余 25%
- 四六级梯度加分（550/600/650）、雅思≥7、托福≥100 追加分
- 干部任职仅一学期按 50%、综测小组长 +5、成员 +3
- 志愿服务按时长 × 级别折算，三下乡负责人上限 14 / 成员上限 12
- 所有分值表与细则原文一一对应

### 数据安全

- 输入即存，自动保存到浏览器 `localStorage`
- 一键导出 JSON 备份、导入恢复
- 支持导出 CSV 明细（可用 Excel 打开核对）
- 支持打印 / 存为 PDF

### 界面

- 响应式布局，手机、平板、电脑均可使用
- F3 内 8 个模块卡片式切换，得分与进度一眼可见
- 结果页展示完整计算过程，便于逐项核对

访问部署后的网址即可，例如：

```
https://你的用户名.github.io/仓库名/
```

### 方式二：本地使用

1. 下载 `index.html` 和 `rules.docx`，放在**同一个文件夹**
2. 双击 `index.html`，用浏览器打开
3. 建议加入浏览器书签

> `rules.docx` 是细则原文，点击页面右上角「📄 细则原文」即可查看。若不需要该功能，只保留 `index.html` 也能正常算分。

## 部署到 GitHub Pages

### 1. 创建仓库

登录 GitHub，点击右上角 **+** → **New repository**

- Repository name：随意，例如 `zongce`
- 可见性选 **Public**（免费账户的 Pages 需要公开仓库）
- 勾选 **Add a README file**
- 点击 **Create repository**

### 2. 上传文件

进入仓库，点击 **Add file** → **Upload files**，把这三个文件拖进去：

```
index.html
rules.docx
README.md
```

点击 **Commit changes**。

### 3. 开启 Pages

仓库页 → **Settings** → 左侧 **Pages**

- **Source**：Deploy from a branch
- **Branch**：`main` + `/ (root)`
- 点击 **Save**

### 4. 等待生效

约 1～2 分钟后刷新页面，顶部会出现：

```
Your site is live at https://你的用户名.github.io/zongce/
```

点击网址即可访问。之后每次修改文件，Pages 会自动重新部署。

### 手机访问

把网址发给自己（微信文件传输助手、备忘录都行），手机浏览器打开即可。建议「添加到主屏幕」，用起来像 App。

## 数据存储与备份

### 数据存在哪里

保存在浏览器的 `localStorage`，键名：

```
hunnu_med_zongce_v1
```

**数据不会上传到 GitHub，也不会发往任何服务器。** 仓库里只有程序代码。

### 换设备 / 换浏览器怎么办

`localStorage` 按「浏览器 + 网址」隔离，不会自动同步。迁移步骤：

1. 旧设备：点击 **导出备份** → 得到 `综测备份_姓名_日期.json`
2. 把 JSON 传到新设备（微信、U盘、网盘均可）
3. 新设备：打开网页 → **导入备份** → 选择该文件

### 注意事项

- ⚠️ **不要把导出的 JSON 备份上传到 GitHub 仓库**，里面包含姓名、学号、成绩等个人信息
- ⚠️ 清理浏览器数据、使用无痕模式、更换网址，都可能导致本地数据丢失
- ✅ 建议每填写一段时间就导出一次备份，成本很低

## 常见问题

**Q：页面打开是空白？**
检查浏览器版本，需支持 ES6。推荐 Chrome、Edge、Safari 或国产浏览器的极速模式。

**Q：「细则原文」按钮点了没反应？**
`rules.docx` 没有和 `index.html` 放在同一目录。补齐即可；或直接忽略该按钮。

**Q：分数和我自己算的对不上？**
先在「结果明细」页对照各项计算说明，那里会列出每个加分项的具体来源。若仍有疑问，检查是否重复计分（同一项目只能取最高分）或超出单项 20 分上限。

**Q：可以多人使用吗？**
每个浏览器独立存储一份数据。同一台设备要算多个人，建议每人填写后导出备份，再清空重填。

**Q：修改了细则怎么办？**
分值表集中在 `index.html` 开头的 `RULES` 对象里，按注释修改对应数值即可。
