## 这是什么

依据《湖南师范大学医学部本科生综合素质测评实施细则》整理的个人算分工具，把「F1 基本素质 + F2 课程成绩 + F3 创新实践」三块拆开填写，实时算出每项得分、封顶情况和综测总分，并额外提供平均学分绩点（GPA）换算，方便评奖评优前自己先核对一遍。

**总分 = F1 × 10% + F2 × 65% + F3 × 25%，满分 100 分**

| 模块 | 权重 | 内容 |
|------|------|------|
| **F1 基本素质** | 10% | A1 思想政治、A2 道德品质、A3 学习态度、A4 组织纪律、A5 身心健康 |
| **F2 课程成绩** | 65% | 学分加权平均，支持优/良/中/及格/不及格自动折算 |
| **F3 创新实践** | 25% | B1 职业技能、B2 学科竞赛、B3 科技学术、B4 文艺宣传、B5 社会工作、B6 社会实践、B7 文体竞赛、B8 劳育 |

## 功能

### 七个标签页

| 标签 | 作用 |
|------|------|
| 👤 基本信息 | 姓名、学号、年级、专业，手动认定「5531」与一票否决 |
| 🎯 5531 指标 | 讲座 / 志愿 / 文体 / 成长辅导四类活动打卡，达标进度条 |
| ① 基本素质 F1 | A1~A5 加减分明细，逐项封顶 20 分 |
| ② 课程成绩 F2 | 逐门课程学分与成绩，学分加权平均，可标记不计入的课程 |
| ③ 创新实践 F3 | B1~B8 八个子模块卡片式切换，进度与得分一目了然 |
| 🎓 绩点 GPA | 平均学分绩点、总学分、逐门课程绩点、校方换算表 |
| 📊 结果明细 | 完整计算过程、F3 构成、总分公式、打印与 CSV 导出 |

顶部汇总条同时显示 F1、F2、F3、平均绩点与综测总分。

### 计分规则落地

- F1 五项每项封顶 20 分（A1 基准 17 + 团校/青马最多 3），单项扣分上限 20 分，一票否决 F1 归零
- B1~B8 每项封顶 20 分；按总则「综测总分满分 100 分」，F3 合计再封顶 100 分
- 「5531」指标自动判定（3 讲座 + 5 志愿 + 5 文体 + 1 成长辅导），达标或手动认定后，B1、B2、B3、B4、B6、B7 各加 5 分基础分
- 团队项目角色折算：B2/B3 第一负责人 100%、第二三负责人 50%、其余 25%；B7 队长与副队长满分、其余 50%
- 四六级梯度加分（550/600/650、500/550/600）；雅思/托福按表 2 计 4 分，雅思 ≥7、托福 ≥100 再 +2；国二评级优秀 +1
- 干部任职只取最高主职（不累加）、任职仅一学期按 50%、综测小组长 +5、成员 +3
- 志愿服务按时长 × 级别折算（上限 10 分），三下乡负责人上限 14 / 成员上限 12
- 毅行/益跑/马拉松 3 分/次、合计上限 6 分（半程按 0.5 次）；献血 2 分/次、上限 4 分
- F2 只计专业必修、公共必修、专业选修，校公选课与辅修课程可标记为「不计入」

### 绩点（GPA）

- 成绩→绩点按校方换算表：100~95→5.0、94~90→4.5、89~85→4.0、84~80→3.5、79~75→3.0、74~70→2.5、69~65→2.0、64~60→1.5、59~0→0
- 平均学分绩点 = Σ(学分 × 课程绩点) ÷ Σ学分，与 F2 同口径（不含校公选课与辅修课程）
- 等级成绩（优/良/中/及格/不及格）先按 95/85/75/65/50 折算，再查表
- 绩点仅作学业参考，**不计入综测总分**

### 证明材料与导出

- 「🎯 5531 指标」页底部可上传活动通知、签到记录、证书截图等图片
- 图片自动压缩到长边 1600px 后存入浏览器 IndexedDB，并可按「讲座/志愿/文体/成长辅导」或 B1~B8 分类关联
- 关联后的缩略图会显示在对应活动类别和 F3 模块下方，点击可全屏查看
- 支持导出 JSON 备份（可含图片）、导出 CSV 明细（Excel 可打开）、打印或存为 PDF

## 部署到 GitHub Pages

1. **新建仓库**：New repository → 名称随意（如 `zongce`）→ 可见性选 **Public** → 创建
2. **上传文件**：Add file → Upload files，把 `index.html`、`rules.docx`、`README.md` 拖进去 → Commit
3. **开启 Pages**：仓库 Settings → 左侧 Pages → Source 选 `Deploy from a branch` → Branch 选 `main` + `/ (root)` → Save
4. **等待生效**：约 1~2 分钟后刷新，页面顶部会出现站点地址；之后每次改动文件会自动重新部署

> [!IMPORTANT]
> 仓库是**公开**的，任何人访问 Pages 地址都能打开页面、查看源码。
> 但请放心：页面本身不含任何个人数据，你的填写内容只存在你自己的浏览器里。
> **千万不要把导出的 `综测备份_*.json` 提交到仓库**——里面有姓名、学号、成绩与证书照片。

## 数据与隐私

### 数据存在哪里

| 内容 | 存储位置 | 说明 |
|------|----------|------|
| 分数、课程、活动记录 | `localStorage` | 键名 `hunnu_med_zongce_v1`，体积小 |
| 证明材料图片 | `IndexedDB` | 数据库 `zongce_media`，容量远大于 localStorage |

**页面不加载任何第三方脚本、字体或统计代码，断网也能正常使用，你的输入不会离开浏览器。**
仓库里只有程序代码，没有后端，也没有数据库。

### 请注意

- GitHub 作为托管方会按惯例记录访问日志（IP、User-Agent 等），这与本项目无关，也不是本项目的统计
- 导出的备份 JSON / CSV 含个人信息，请勿提交到仓库，也不要在公开群里分享
- 清理浏览器数据、使用无痕模式、浏览器回收存储空间、更换域名或仓库名，都可能导致本地数据丢失
- `localStorage` 与 `IndexedDB` 按「浏览器 + 网址」隔离：用 `file://` 打开和用 Pages 打开是两份独立数据，需要手动导出/导入迁移

建议在仓库根目录放一个 `.gitignore`，避免手滑提交备份文件：

```gitignore
# 个人数据备份，含姓名 / 学号 / 成绩 / 证书照片，请勿提交
综测备份_*.json
综测完整备份_*.json
综测明细_*.csv
```

## 已知限制

- 计分依据的是 2025—2026 学年版本细则；学部若更新细则，需要自行修改 `index.html` 开头的 `RULES` 对象
- 部分条款存在解释空间。例如 F3 八项各自上限 20 分、相加可达 160 分，本项目按总则「综测总分满分 100 分」对 F3 合计封顶 100；若学部另有口径，可调整 `RULES.F3_CAP`
- 补考、缓考不做自动识别，请按「补考前成绩」手动填写
- 未在全部浏览器与机型上做过兼容性验证；遇到显示或计算问题，欢迎提 Issue
- 纯静态、无后端，因此没有云端同步、多人协作或账号体系

## 常见问题

**Q：页面打开是空白？**
浏览器需支持 ES6 与 IndexedDB。推荐 Chrome、Edge、Safari 或国产浏览器的「极速模式」。

**Q：「细则原文」按钮点了没反应？**
`rules.docx` 没有和 `index.html` 放在同一目录。补齐即可；或直接忽略该按钮。

**Q：分数和我自己算的对不上？**
先看「结果明细」页，那里会列出每个加分项的具体来源。常见原因：同一项目重复计分（应取最高分）、超出单项 20 分上限、或「5531」未达标导致 5 分基础分未计入。

**Q：上传的图片存在哪里？会不会传到网上？**
存在浏览器的 IndexedDB 里，只在本机。网页是静态文件，没有后端，图片不会离开你的设备。

**Q：导出的备份包含图片吗？**
导出时会询问。选「确定」会把图片转成 Base64 一并打包，文件会比较大（几十张可能 10 MB 以上）；选「取消」只导数据。

**Q：换电脑后图片丢了？**
说明之前用的是「仅数据」备份。图片无法通过普通备份还原，需要重新上传。以后请用「完整备份」。

**Q：可以多人使用吗？**
每个浏览器独立存储一份数据。同一台设备要算多个人，建议每人填完导出备份，再清空重填。

**Q：手机上能用吗？**
可以，页面是响应式布局。建议在手机浏览器里「添加到主屏幕」。

**Q：修改了细则怎么办？**
分值表集中在 `index.html` 的 `RULES` 对象里，按注释修改对应数值即可；版本号 `APP_VERSION` 也建议同步更新。
